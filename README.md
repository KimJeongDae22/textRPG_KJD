# textRPG_KJD
프로그래밍 기초 주차 (04/14 ~04/18) 개인 과제입니다.
----
## 📘 프로젝트 소개
- 개요
  - 내일배움캠프 2주차인 프로그래밍 기초 주차의 개인 과제인 ‘텍스트 RPG (스파르타 던전)’ 입니다. 콘솔창을 통해 게임이 진행이 되고 플레이어는 텍스트를 통해 게임의 진행상황을 알 수 있게 됩니다.
  - ***유니티 파일이 있긴 하지만 이건 레포지토리 생성 연습으로 넣어본거고 개인 과제는 비쥬얼 스크립트 파일(.cs)로만 진행되기에 textRPG 폴더에 있는 것만 살펴보시면 될 것 같습니다.***
- 게임 방법
  - 게임 시작 시 간단한 소개말과 함께 마을에서 할 수 있는 행동을 알려줍니다.
  - 원하는 행동에 해당하는 숫자를 입력하면 그에 맞는 행동을 실행합니다
  - 제시된 숫자 이외의 숫자 입력 시 "잘못된 입력입니다" 문장을 출력합니다.
  - 상태 보기, 인벤토리 (장착 관리), 상점 (아이템 구매) 등의 기능을 이용할 수 있습니다.
<details>
  <summary><b>코드 설명</b></summary>
    <ui>
      <li>플레이어와 아이템은 구조체로 설정했습니다. 플레이어는 체력, 공격력 등의 능력치를 포함하고, 아이템은 아이템 이름, 설명 등의 요소를 포함하고 있습니다.</li>
      <li>아이템 구조체에 배열로 만들어서 인벤토리를 구현했습니다. 인벤토리 크기는 20으로 설정했습니다.</li>
      <li>마을에서의 화면이나 상점, 인벤토리 등등은 모두 메서드의 형식 (ex. void Inventory() ) 으로 설정하여 구간마다 관리를 보다 쉽게 하도록 설정하였습니다.</li>
      <li>플레이어의 레벨업이나 아이템의 장착/해제는 구조체 내에서 매서드를 만들어 자주 이용되는 작업을 효율적으로 관리하도록 했습니다.</li>
      <li>특정 부분(던전 클리어 결과, 상점으로 인한 아이템 획득) 에서는 메서드에 매개 변수를 할당하여 배열 값이나 인덱스 값에 접근하기 용이하게 설정했습니다.</li>
    </ui>
</details>
- 아쉬운 점
  - 인벤토리 기능을 리스트로 구현하려 했으나 아직 미숙하여 적용하지 않았습니다.
  - 구현 기능 대부분 void 형식의 메서드로만 이루어져 있어 다양한 방법을 적용해보지 못해 아쉬웠습니다.
  - 아이템 구조체 부분에서 방어구와 무기 불리언 변수를 각각 따로 만들었는데 그것보다 정수형으로 변수를 하나만 만들어 1이면 무기, 2면 방어구 같은 식
    으로 만들면 좀 더 깔끔한 방식으로 할 수 있을거라는 아쉬움이 작업 후반에 들었습니다.
